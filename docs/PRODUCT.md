# キラキラセキュリティ 製品説明資料（販売用）

## キャッチコピー

**「インストールして 1 コマンド。あなたの API キー、漏れてませんか？」**

SNS 運用ツールを使う人が一番怖いのは、アカウントの乗っ取り。
その原因のほとんどは「API キーのうっかり漏えい」です。
キラキラセキュリティは、プログラミング初心者でも使える**日本語のセキュリティ診断ツール**です。

## こんな人のためのツールです

- X (Twitter) の Bot やツールを動かしていて、API キーを持っている人
- GitHub にコードを公開しているが、セキュリティに自信がない人
- 「何をチェックすればいいのかすら分からない」プログラミング初心者

## できること（機能一覧）

### 1. シークレット漏えい診断

コードの中に「書いてはいけないもの」が書かれていないかを自動検出します。

**検出できるシークレットの種類:**

| 種類 | 例 |
| --- | --- |
| X (Twitter) Bearer Token | `AAAAAAAAA...` 形式 |
| AWS アクセスキー | `AKIA...` 形式 |
| GitHub トークン | `ghp_...` / `gho_...` など |
| Google API キー | `AIza...` 形式 |
| Slack トークン | `xoxb-...` など |
| OpenAI などの API キー | `sk-...` 形式 |
| 秘密鍵ファイル | `-----BEGIN PRIVATE KEY-----` |
| 汎用パターン | `password = "..."` のような直書き |

### 2. 過去にさかのぼる履歴スキャン（--history）

「今は消してあるから大丈夫」は通用しません。git は過去の全履歴を保存しているため、
**昔のコミットに埋もれたキーも第三者から復元できます**。
`--history` オプションは全コミット履歴をさかのぼってスキャンし、埋もれたキーを発見します。

### 3. 設定ミス診断

- `.env`（キー保存ファイル）を誤ってコミットしていないか
- `.gitignore` の除外設定が正しいか
- `.env` が他のユーザーからも読めるファイル権限になっていないか

### 4. 依存パッケージの脆弱性診断

使っているライブラリに既知の脆弱性（CVE）が報告されていないかをチェックします
（[PyPA Advisory Database](https://github.com/pypa/advisory-database) と照合）。

### 5. ワンコマンド自動修復（--fix）

見つけるだけでなく、直せるものは自動で直します。

- `.gitignore` への `.env` 追加
- `.env` のファイル権限を「自分だけが読める」設定に変更

自動で直せない問題（キーの再発行が必要なものなど）は、
**実行するコマンド付きの日本語**で直し方を案内します。

### 6. セキュリティスコアとランク判定

診断結果を **100 点満点のスコア**と **S / A / B / C のランク**で表示。
危険度の高い問題ほど大きく減点されるので、今の状態がひと目で分かります。

| ランク | スコア | 状態 |
| --- | --- | --- |
| S | 100 点 | 完璧。すべてのチェックに合格 |
| A | 80〜99 点 | おおむね安全。小さな改善点あり |
| B | 60〜79 点 | 要注意。早めの対応を推奨 |
| C | 59 点以下 | 危険。キー漏えいの可能性あり、今すぐ対応 |

### 7. JSON レポート出力（--json）

診断結果を JSON 形式で出力できます。CI への組み込みや、他のツールとの連携に使えます。
問題があると終了コード 1 を返すため、GitHub Actions などで「問題があったらビルドを止める」運用ができます。

## 仕様

| 項目 | 内容 |
| --- | --- |
| 対応 OS | Windows / macOS / Linux（ファイル権限チェックは macOS / Linux のみ） |
| 動作環境 | Python 3.9 以上 |
| インストール | `pip install ".[security]"` の 1 コマンド |
| 実行 | `kirakira security` の 1 コマンド |
| オプション | `--fix`（自動修復）/ `--history`（履歴スキャン）/ `--json`（レポート出力） |
| チェック項目数 | 6 項目（シークレット検出は 8 パターン） |
| 表示言語 | すべて日本語（直し方の案内付き） |
| 通信 | **診断データの外部送信なし**。すべてローカルで完結（脆弱性照合時のみ公開データベースを参照） |
| 診断時間 | 数秒（履歴スキャン込みでもリポジトリが巨大でなければ数十秒以内） |

## できないこと（正直にお伝えします）

- **ウイルス対策ソフトではありません。** マルウェアの検出・駆除はできません。
- **リアルタイム保護ではありません。** 実行したときだけ診断します（CI に組み込めば push のたびに自動実行できます）。
- **検出は 100% ではありません。** パターンに一致しない独自形式のキーは見逃す可能性があります。
- 対象は **git で管理された Python プロジェクト**です。

## 使い方（3 ステップ）

```bash
# 1. インストール（最初の 1 回だけ）
pip install ".[security]"

# 2. 診断
kirakira security --history

# 3. 直せるものは自動修復
kirakira security --fix
```
