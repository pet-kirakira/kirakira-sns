# 年間予定表（指定管理）

指定管理施設向けの **年間予定表** 作成アプリです。年度（4月〜翌3月）単位で
行事・予定を入力し、**A3 用紙 1 枚**に印刷できます。

日本で一般的な「縦＝1〜31 日 × 横＝4月〜3月」の 1 枚レイアウトを採用しています。

## 特長

- **年度ベース**：4 月始まり〜翌 3 月まで（令和表記に対応）
- **予定の入力**：セルをクリックしてそのまま入力（自動保存）
- **予定を入れた日は色が変わる**：予定あり＝黄色＋左の色バーで一目で分かる
- **曜日・祝日の色分け**：日曜=赤 / 土曜=青 / 祝日=赤（祝日名も表示）
- **祝日を自動計算**：春分・秋分、ハッピーマンデー、振替休日、国民の休日に対応
- **A3 横で印刷**：「A3 で印刷」ボタン → ブラウザの印刷で A3 横 1 枚に収まる
- **データの保存**：ブラウザ内（localStorage）に自動保存。JSON で書き出し／
  読み込みができ、共有・バックアップ・他 PC への移行が可能

## 使い方

1. `nenkan_yotei/index.html` をブラウザで開く（ダブルクリックで OK）
2. 「年度」を選び、「施設名 / 事業名」を入力
3. カレンダーのセルをクリックして予定・行事を入力（自動で保存されます）
4. 「🖨 A3で印刷」を押して、印刷ダイアログで用紙サイズ **A3・横** を選んで印刷

### データの共有・保管

- **⬇ 書き出し(JSON)**：`nenkan_yotei_<年度>.json` として保存
- **⬆ 読み込み(JSON)**：書き出した JSON を読み込んで復元

> データはブラウザごとに保存されるため、別の PC やブラウザで使う場合は
> JSON で書き出して受け渡してください。

## 印刷のコツ

- 印刷ダイアログで **用紙：A3 / 向き：横 / 余白：既定** を選択
- 「背景のグラフィック」を有効にすると、土日祝や予定の色も印刷されます
- 1 枚に収まらない場合は「拡大縮小：用紙に合わせる」を選択

## 技術メモ

- 追加ライブラリ不要の単体 HTML（HTML/CSS/JavaScript のみ）
- 祝日は内蔵の計算ロジックで算出（1980〜2099 年頃の範囲で有効）
- 保存先は現在ローカル（localStorage）。将来 Google カレンダー等の
  外部保存に切り替える場合も、JSON（`{ fiscalYear, facility, events }`）を
  入出力の基本形式として拡張できます
