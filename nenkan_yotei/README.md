# 年間予定表（指定管理）

指定管理施設向けの **年間予定表** を作成するツールです。年度（4月〜翌3月）単位で
行事・予定を入力し、**A3 用紙 1 枚**に印刷できます。

2 つの使い方を用意しています。

| 用途 | ツール | 特長 |
|------|--------|------|
| その場で入力・A3印刷 | **HTMLアプリ** `index.html` | インストール不要。ブラウザで開くだけ |
| **複数人で共有・編集** | **Excel生成** `excel.py` | 生成した `.xlsx` を共有ドライブ / OneDrive / Teams に置いて共同編集 |

どちらも共通のデータ（JSON）でつながっており、
**HTMLアプリで入力 → JSON書き出し → Excel生成** という流れも、
**最初から Excel に直接入力**も、どちらも可能です。

## 共通の機能

- **年度ベース**：4 月始まり〜翌 3 月まで（令和表記に対応）
- **予定ごとに色・アイコンを指定**できる
- **数日間にわたる予定**（開始日〜終了日）に対応
  - カレンダー上で同じ色が縦につながり、期間が一目で分かる
- **曜日・祝日の色分け**：日曜=赤 / 土曜=青 / 祝日=赤（祝日名も表示）
- **祝日を自動計算**：春分・秋分、ハッピーマンデー、振替休日、国民の休日に対応
- **A3 横で印刷**

---

## 1. HTMLアプリ（`index.html`）

1. `nenkan_yotei/index.html` をブラウザで開く（ダブルクリックで OK）
2. 「年度」を選び、「施設名 / 事業名」を入力
3. カレンダーのセルをクリック → ダイアログで **件名・アイコン・色・期間**を設定
   （既存の予定はクリックで編集・削除）
4. 「🖨 A3で印刷」→ 印刷ダイアログで用紙 **A3・横** を選んで印刷

データはブラウザ内（localStorage）に自動保存され、
**⬇ 書き出し(JSON)** / **⬆ 読み込み(JSON)** で共有・バックアップができます。

---

## 2. Excel生成（`excel.py`）

複数人で共同編集したい場合はこちら。`.xlsx` を生成します。

```bash
pip install -r requirements.txt   # openpyxl が必要

# (A) 空のテンプレートを作る（Excelに直接入力する用）
python -m nenkan_yotei.excel --year 2026 --facility "○○指定管理施設"

# (B) HTMLアプリで書き出したJSONから予定を流し込む
python -m nenkan_yotei.excel --input nenkan_yotei_2026.json
```

### オプション

| オプション | 説明 |
|-----------|------|
| `--year`     | 年度（西暦・4月始まり）。省略時は当年度 |
| `--facility` | 施設名 / 事業名 |
| `--input`    | 予定JSON（HTMLアプリの書き出し）。年度・施設名も引き継ぐ |
| `--output`   | 出力先 `.xlsx`（省略時 `nenkan_yotei_<年度>.xlsx`） |

### 生成される Excel

- 各月ごとに「曜」「予定」の 2 列 × 1〜31 日の年間 1 枚レイアウト
- 土日祝の色分け・祝日名を表示
- 予定は淡い色で塗り＋左に色の縦線、アイコン（絵文字）＋件名を表示
- **数日間の予定は同じ色でセルが縦に連続**（先頭日・月替わりに件名を表示）
- **A3 横・1 ページに収まる印刷設定**（余白・中央寄せ・見出し固定を設定済み）
- 共同編集しやすいよう **セル結合は使用していません**

### 複数人での運用イメージ

1. 生成した `.xlsx` を **OneDrive / SharePoint / Teams / 共有フォルダ**に置く
2. 各担当者が Excel で開き、予定を追記（塗りつぶし色や絵文字も Excel 上で編集可）
3. 印刷時は用紙 **A3・横**、必要に応じて「シートを 1 ページに印刷」を選択

## 技術メモ

- HTMLアプリ：追加ライブラリ不要の単体 HTML（HTML/CSS/JavaScript のみ）
- Excel生成：Python + `openpyxl`
- 祝日は内蔵ロジックで算出（`holidays.py` / 1980〜2099 年頃の範囲で有効）
- データ形式（JSON）：
  ```json
  {
    "fiscalYear": 2026,
    "facility": "○○指定管理施設",
    "events": [
      { "title": "夏まつり", "icon": "🎉", "color": "#e05a5a",
        "start": "2026-08-01", "end": "2026-08-03" }
    ]
  }
  ```
